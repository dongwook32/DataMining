## 2. 연구 A: 단일 국면 vs 다중 국면 활성화 비교 분석

### 2.1 분석 배경 및 비교 설계
기존 거시경제 뉴스 연구는 각 시점에서 가장 비중이 큰 단 하나의 대표 토픽(Dominant Topic)만을 선택하거나 단일 지수로 축약하는 방식을 주로 채택하였다. 그러나 현실 경제에서는 복수의 경제 이슈가 동일 월에 동시에 활성화되는 복합 현상이 빈번하다.
본 실험에서는 동일한 Phase 5.6 고정 모수($z \ge 0.5$) 하에서 다음 세 방식을 비교하였다:
- **방식 A-1 (Unconstrained Argmax):** 점수 크기와 무관하게 무조건 월별 최대 국면 1개만 선택.
- **방식 A-2 (Hurdle Argmax):** 최대 국면이 $z \ge 0.5$ 이상일 때만 선택하고 미달 시 '비활성(`none`)' 처리.
- **방식 B (Multi-activation):** $z \ge 0.5$를 만족하는 모든 국면을 동시 활성화.

### 2.3 해석 및 학술적 평가
1. **단일 대표 국면 표현의 구조적 차이 (43.75%):**
   - 전체 67개월 중 2개 이상의 경제 국면이 동시에 활성화된 월은 **58.21%(39개월)**이며, 학습 기간(48개월)에서는 **66.67%(32개월)**, 테스트 기간(19개월)에서는 **36.84%(7개월)**로 확인되었다.
   - 단일 대표 국면 방식으로 표현을 제한할 경우, 다중 국면 방식에서 관측된 활성 국면 신호 중 **43.75%(112건 중 49건)**가 별도 국면으로 표현되지 않는다. 이는 표현상 정보 보존성에 관한 결과이며 예측 정확도의 개선을 의미하지는 않는다.
2. **실제 관측된 동시 활성화 국면 조합 (`single_vs_multi_regime_combinations.csv` & `single_vs_multi_monthly.csv`):**
   - 전체 67개월에서 가장 빈번히 관측된 2국면 단독 조합은 `market;earnings`(5개월: 학습 3, 테스트 2), `aichip;capital`(4개월: 학습 4), `macro;realestate`(3개월: 학습 3), `realestate;capital`(3개월: 학습 3), `earnings;capital`(3개월: 학습 2, 테스트 1) 순이다.
   - 3국면 동시 활성 월(10개월)까지 포함한 쌍별 동시 활성화 빈도를 보면, 2022년 중 `macro`와 `realestate`의 동시 활성화가 5개월(2국면 단독 3 + 3국면 2), 2022~2023년 중 `macro`와 `market`의 동시 활성화가 5개월(2국면 단독 2 + 3국면 3) 관측되었으며, 2022~2023년 중 `macro`와 `capital`의 동시 활성화는 0개월(전 기간 중 `2024-12`의 `macro;market;capital` 1개월만 존재)이었다.

## 3. 연구 B: 뉴스와 네이버 검색 관심도의 주별(Weekly) 교차 검증

### 3.1 분석 배경 및 설계
- **목적:** 뉴스 텍스트에서 비지도 학습으로 추출한 경제 국면 점유율의 주간 변동이 일반 대중의 네이버 검색 관심도 주간 변동과 동시점에 동조하는지 검증함.
- **분석 단위:** `2020-W53 ~ 2026-W31` 총 292개 ISO 주차(Train 209주, Eval OOS 83주; 1차 차분 후 $h=0$ 유효 표본 수 Train $N=208$, Eval OOS $N=82$, Full $N=291$).
- **정상성 및 HAC·다중검정 보정:** 각 구간 내부에서 주간 **1차 차분(First Difference)**을 적용하고, **Newey-West HAC 표준오차(`maxlags=4`)** 및 **8개 매칭 쌍 $\times$ 3개 시차($h \in \{-1, 0, +1\}$) = 24개 검정 패밀리 기준 Holm-Bonferroni 보정(`hac_p_holm`)**을 적용함(`news_search_hac_results.csv`).

### 3.3 시차($h=-1, +1$) 및 앵커 민감도 분석 결과
- **동시점($h=0$) 반응 및 1주 시차($h=\pm 1$) 양(+)의 선행성 부재:** 모든 국면 쌍에서 $h=-1, +1$의 유의한 양(+)의 선행 상관은 없었으며, 시황($h=-1$)과 금리($h=\pm 1$)에서는 급등 직후 기저효과로 인한 음(-)의 반전 상관이 관측되었다.
- **`첨단산업(전기차·배터리 중심)`(`aichip`) 차분 비유의성:** 코드 식별자 `aichip`에 매핑된 토픽 12는 주요 키워드가 `차량, 전기차, 자동차, 현대차, 충전, 배터리` 등에 집중되어 있어(`supported_ev_battery_only`), 생성형 AI·반도체 전반을 포괄하는 검색어 그룹과 의미적 범위 차이가 존재한다.
- **앵커(`'은행'`) 민감도 점검 (`news_search_anchor_sensitivity.csv`):** 앵커 지수(`anchor_score`)로 나누지 않은 원래 상대 검색 지수(`score`, 조회 구간 내 최댓값=100 기준 상대 지표)의 주간 1차 차분에서도 전체 구간 금리($r=+0.5290$), 시황($r=+0.5330$), 금리+물가($r=+0.3651$), 기업실적($r=+0.3464$) 및 테스트 구간 시황($r=+0.5355, \text{HAC } p_{\text{holm}}=0.0327$), 기업실적($r=+0.5508, \text{HAC } p_{\text{holm}}=0.00016$)의 유의성이 일관되게 유지되었다(단, `score` 역시 상대 검색 지표이므로 절대 검색량으로 해석하지 않음).
