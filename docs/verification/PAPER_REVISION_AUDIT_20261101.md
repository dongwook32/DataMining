## 2. 추가 실증 연구 결과의 논문 반영 내역

### 2.1 연구 A: 단일 국면 vs 다중 국면 비교 (`single_vs_multi_metrics.csv`)
- **반영 위치:** 논문 Ⅳ장 4.2절 (표 2)
- **핵심 수치:**
  - 전체 기간 복합 국면($\ge 2$) 비율: **58.21%** (학습 기간: **66.67%**, 테스트 기간: **36.84%**)
  - 총 활성 국면 신호 수: 112건 (월평균 1.672개)
  - 단일 대표 국면(Argmax) 선택 시 누락 신호 수: 49건
  - 활성 신호 정보 누락률: **43.75%** ($49 / 112$)
- **해석 제한 준수:** '경제 정보 손실'이나 '예측 성능 우수성'이라는 단정 대신, **"복합적으로 발생한 활성 이슈 신호의 43.75%가 단일 국면 방식에서는 표현되지 못하고 누락된다"**는 정보 보존성의 관점으로만 기술함.

### 2.2 연구 B: 뉴스와 네이버 검색 데이터 주별 교차 검증 (`news_search_hac_results.csv`)
- **반영 위치:** 논문 Ⅳ장 4.4절 (표 4)
- **Newey-West HAC(maxlags=4) 표준오차 및 Holm 보정 반영:**
  - **시황 뉴스 ↔ 국내증시 검색 ($h=0$):** Train $r = +0.6478$ ($p_{\text{holm}} < 0.001$), Eval OOS $r = +0.4984$ (HAC $p_{\text{holm}} = 0.043$)
  - **기업실적 뉴스 ↔ 기업실적 검색 ($h=0$):** Train $r = +0.2160$ ($p_{\text{holm}} = 0.014$), Eval OOS $r = +0.4718$ (HAC $p_{\text{holm}} = 0.001$)
  - **금리·물가 뉴스 ↔ 금리 검색 ($h=0$):** Train $r = +0.5511$ ($p_{\text{holm}} < 0.001$), Eval OOS $r = +0.3397$ (HAC 원 $p = 0.0170$)
- **네이버 상대점수 공통 분모(anchor_score) 영향 점검:**
  - 일별 앵커 키워드 변동이 주간 1차 차분 시계열에 인위적 왜곡을 주지 않음을 스크립트로 확인하고, "별도의 검색 채널을 이용한 주별 교차 데이터 동조성"으로 엄격히 한정 기술함.
- **차분 후 비유의 국면 명시:** 부동산 및 AI반도체는 수준값 상관과 달리 1차 차분 시 통계적 유의성이 소멸($p_{\text{holm}} = 1.0$)됨을 정직하게 명시함.

### 2.3 연구 C: 인간 평가 셋업 현황
- **반영 위치:** 논문 Ⅳ장 4.5절
- **내용:** 테스트 기간 기사 380건($N=380$)에 대한 19개월 균등 층화 무작위 추출 및 독립 평가자 2인 블라인드 파일(`batch_A.csv`, `batch_B.csv`) 구축 내역을 기술하되, 평가 결과(Cohen's kappa, F1)를 가상으로 생성하지 않고 **"후속 검증 과제"**로 명확히 처리함.

## 3. 최종 논문의 3대 학술적 기여

1. **방법론적 기여 (다중 국면 정보 보존성 입증):**
   - 단일 대표 토픽 강제 방식이 복합 거시 충격의 **43.75%를 절단·누락**시킨다는 사실을 정량적으로 증명하고, 다중 활성화 체계의 정보 보존적 우위를 입증함.
2. **검증 설계의 기여 (무누수 Strict OOS 체계 확립):**
   - 48개월 학습 기간만으로 어휘, IDF, NMF 기저 행렬($H$), 표준화 모수를 고정하고 테스트 기간(19개월)으로 확장 투영하는 결정론적 Strict OOS 파이프라인을 확립함.
3. **실증적 기여 (이종 검색 빅데이터와의 주별 차분 동조성 입증):**
   - 비정상 단위근 추세를 제거한 1차 차분 시계열과 Newey-West HAC 검정을 통해, 뉴스 국면(시황, 기업실적, 금리)이 네이버 검색 관심도와 주 단위에서 실시간으로 유의하게 동조함을 표본 외 테스트 기간에서도 교차 검증함.

## 4. 남아 있는 학술적 한계 및 향후 과제

1. **예측력 및 인과성 미주장:** 뉴스 국면과 시장 수익률 간의 유의성은 동행적 설명 관계이며, 미래 예측력이나 인과관계를 의미하지 않음을 명시함.
2. **가계부채·대외통상 미형성 한계:** 비지도 NMF의 고유 특성상 두 국면이 독립 토픽으로 분리되지 못하였으며, 향후 준지도 학습이나 대형 언어 모델(LLM) 기반 보완이 필요함.
3. **인간 라벨링 회수 과제:** 380건 표본에 대한 실제 평가자의 라벨링 입력이 완료된 후 모델과의 다중 라벨 F1 정량 평가를 완료할 예정임.
