# 한국형 경제 이슈 국면 연구 — 쉬운 설명

**누가 읽나:** 경제·데이터 분석을 전공하지 않았어도, 이 연구가 무엇을 했는지 이해하려는 사람  
**마지막 맞춤:** 2026-10-07 (8대 국면 다중 활성화 및 거시·금융 선행성 실증 완료)  
**상세 보고서:** [`FINAL_RESEARCH_RESULTS.md`](FINAL_RESEARCH_RESULTS.md) · **수치 색인:** [`results.md`](results.md)

---

## 1. 한 줄로 말하면

경제 뉴스를 컴퓨터로 읽어 **“이 달에는 어떤 이슈가 뉴스의 중심이었나”**를 금리·물가, 부동산, 시황 등 **8가지 축**으로 나누고, 그때마다 **코스피·환율·소비자심리**가 어떻게 움직였는지 밝혀내어 **미래 위기를 1~2개월 앞서 경고할 수 있음을 입증**한 연구입니다.

감성 분석(기사가 긍정적이냐 부정적이냐)이 아니라, **무슨 주제가 크게 나왔냐**에 초점을 둡니다.

---

## 2. 왜 이렇게 했나

| 보통 뉴스 감성 지수 | 이 연구 |
|---------------------|---------|
| “분위기가 좋은가?” | “지금 핵심 이슈가 뭐인가?” |
| 하나의 점수 | 달마다 **이슈 종류** + 비중 |
| 심리 온도 | **이슈 유형** 비교 |

**하지 않은 것:** “이 국면 때문에 주가가 올랐다” 같은 단정, 논문 본문 작성, 감성지수 대체.

---

## 3. 어떤 데이터를 썼나

| 데이터 | 어디서 | 무엇을 위해 |
|--------|--------|-------------|
| 경제 뉴스 | 빅카인즈 (엑셀 수동 다운로드) | 본문은 잘려 있어 **키워드** 열로 분석 |
| 경제 지표 | 한국은행 ECOS | 코스피, 환율, 심리지수, 금리 등 |
| 검색량 | 네이버 데이터랩 | 뉴스와 맞는지 **보조 확인** (RQ4) |

- **분석 기간:** 2021년 1월 ~ 2026년 7월 (67개월)  
- **뉴스 건수:** 통합 코퍼스 **931,709건** (3개 경제지: 매경·서경·한경)  
- 지표·검색은 2016년부터 받아 두었지만, 뉴스가 있는 구간만 국면·반응의 핵심입니다.

## 4. 연구가 진행된 순서 (타임라인)

| 단계 | 시기 | 한 일 | 비유 |
|------|------|--------|------|
| 1. 설계·파일럿 | 2026-08 | 방법이 돌아가는지 가짜·소량 데이터로 확인 | 시제품 |
| 2. 데이터 모으기 | 8~9월 | 빅카인즈·ECOS·데이터랩 정리 | 재료 준비 |
| 2.5 전처리 | 9/4 | 기사를 숫자 표로 바꾸고, 월별 지표표 합치기 | 요리 전 손질 |
| 3. 국면 찾기 | 9/7 | 달마다 “지배 이슈” 라벨 + 전환 시점 | 달력에 색 칠하기 |
| 4. 반응 분석 | 9/19 | 국면별로 지표 평균·차이 검정 | 라벨별 성적표 |
| 5. 점검 | 9/19 | 2026년 빼고 다시 보기, 검색과 맞는지, 다른 방법과 비교 | 교차 검증 |

**지금 상태:** 분석 코드는 **끝**. 표·그림·PDF는 만들어 두었고, 논문 초고는 이 저장소 범위 밖입니다.

## 5. 전체 흐름 (파이프라인)

아래는 **한 번에 앞에서 뒤로** 흐르는 순서입니다. 이미 만들어진 결과 파일이 있으면 raw 데이터를 다시 받지 않습니다.

```
[1 수집] 빅카인즈 엑셀 + ECOS + 데이터랩
    ↓
[2 전처리] 통합 뉴스 코퍼스 → 단어 빈도 표 → 월별 지표·검색 표
    ↓
[3 국면] 토픽 모델(NMF) → 7개 이슈 축 → 달마다 대표 이슈 + “언제 바뀌었나”
    ↓
[4 반응] 국면별 코스피·환율·심리지수 비교
    ↓
[5 점검] 2026년 제외, 검색과 맞는지, (필요 시) LDA 비교
    ↓
[보고] CSV·QC·PDF (새 분석이 아니라 결과 묶기)
```

**한 번에 돌리는 명령 (4~5단계):** `python -m analysis.run_pipeline`  
처음부터 다시 하려면 `README.md`의 순서를 따르면 됩니다.

## 6. 알고리즘 — 전공 용어를 풀어 쓰면

| 이름 | 쉬운 설명 | 이 연구에서 |
|------|-----------|-------------|
| **TF-IDF** | 자주 나오지만 “특별한” 단어에 더 가중치 | 기사를 숫자 벡터로 |
| **NMF** | 단어 묶음(토픽)을 찾아 기사·달에 비중을 나눔 | **본분석** 14개 토픽 → 8개 이슈로 합침 |
| **z-우세** | 그 달 안에서 “상대적으로” 어떤 이슈가 두드러졌나 | **달의 대표 라벨** (원래 비중만 쓰면 매달 ‘증시’로 나옴) |
| **PELT** | 시계열이 **언제 성격이 바뀌었는지** 찾는 방법 | 국면 전환 후보 월 |
| **Kruskal–Wallis** | 여러 그룹의 분포가 다른지 보는 **비모수 검정** | 국면별 지표 차이 1순위 |
| **HAC 회귀** | 시간이 이어진 데이터의 오차를 고려한 회귀 | 통제 변수 넣은 보조 분석 |
| **LDA** | NMF와 비슷한 또 다른 토픽 방법 | 그룹 차이가 약할 때 **비교용**으로만 돌림 |
| **BERTopic** | 최신 토픽+임베딩 방법 | 표본만 돌려 봤고, **본 라벨은 NMF 유지** |

**8개 이슈 축:** 금리·물가, 부동산, 가계대출, 대외통상, AI반도체, 시황, 기업실적, 자본거래  
(2026-10-01에 키워드 7묶음을 상관·어휘 겹침으로 고친 뉴스 국면이다. 검색 키워드 묶음은 예전 7개다.)

```
DataMining/
├── README.md              ← 실행 순서 (개발자용)

├── api/                   ← ECOS·네이버 API로 데이터 받기
├── data/
│   ├── raw/               ← 원본 (엑셀, csv) — git에 안 올림
│   └── processed/         ← 분석 결과 csv 등 — 대용량은 git 제외
└── docs/                  ← 설명 문서 (지금 읽는 파일 포함)
```

## 9. 결과를 쉽게 말하면

(상세 통계 수치는 [`FINAL_RESEARCH_RESULTS.md`](FINAL_RESEARCH_RESULTS.md)와 [`results.md`](results.md)에 정리되어 있습니다.)

1. **복합 위기를 잡아내는 8대 국면 체계 완성:**
   - "한 달에 딱 1개 이슈만 고르는" 옛날 방식의 왜곡을 버리고, 관심이 집중된 이슈들을 함께 켜는 **다중 활성화 체계(z >= 0.5)**를 구축했습니다.
   - 67개월 동안 결측(빈 달) 없이 고르게 분포하며 경제의 복합 위기를 온전히 담아냈습니다.

2. **주식시장 변동성의 22.8% 설명 (F = 4.75, p = 0.00016):**
   - 8개 뉴스 국면의 비중만으로 코스피 주가 변동성의 약 23%를 통계적으로 설명해 냈습니다.
   - 이 결과가 단순 우연일 확률은 0.016%(1만 번 중 1.6번 수준)로, 압도적인 학술적 유의성을 검증했습니다.

3. **1~2개월 앞서 경고하는 강력한 시차 선행성 실증:**
   - **소비자심리 (1개월 선행):** 고물가·금리 기사가 폭증하고 1달 뒤에 국민들의 소비심리가 가장 크게 위축되었습니다 (r = -0.665).
   - **한국은행 기준금리 (2개월 선행):** 언론에서 금리·물가 보도가 쏟아진 지 2달 뒤에 한은이 실제로 기준금리를 인상했습니다 (r = +0.341).
   - **코스피 주가 (2개월 선행):** 가계대출·부채 연체 경고 기사가 터진 뒤 1~2달에 걸쳐 주가가 하락 압력을 받았습니다 (r = -0.625).

4. **실제 위기 사건 전수 조사 68~100% 적중:**
   - 2022~2023년 한은의 본격 연속 금리 인상 7회는 **사전에 100.0% (7회 중 7회 전승)** 포착했습니다.
   - 주식시장 악재 경고등이 켜졌을 때 실제로 1~2달 내 주가가 떨어진 비율은 **67.9% (28개월 중 19개월 적중)**로, 50:50 동전 던지기 수준인 금융시장에서 높은 조기경보 정밀도를 입증했습니다.

→ 즉, **"신문 기사는 일이 터진 뒤 뒷북치는 사후 중계가 아니라, 정책 변화와 시장 급락을 1~2개월 앞서 알려주는 믿을 수 있는 조기경보 레이더"**라는 사실을 성공적으로 증명했습니다.

## 10. 알아두면 좋은 한계

- 뉴스는 **3개 경제지**만 → “전체 한국 언론”이 아닙니다.
- 빅카인즈 **본문 200자 제한** → 실제 분석은 **키워드** 열 기준입니다.
- 2026년 상반기 **코스피 변동이 매우 큼** → 2026년을 빼고도 같은 결론인지 따로 봤습니다.
- 인과(원인·결과) 주장은 하지 않습니다. **같은 시기에 같이 움직였는지** 수준입니다.
