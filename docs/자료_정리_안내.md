## 데이터와 코드

- `../data/processed/panel/`, `regimes/`, `reactions/`: 패널, 국면, 반응 분석 산출물. 분석 코드가 경로를 참조합니다.
- `../data/processed/reviewer_readiness/`: 심사 대응 검증 기록과 산출물.
- `../data/processed/supplemental_validation/`: 추가 검증 산출물.
- `../data/raw/`: 빅카인즈·ECOS·데이터랩 폴더에 설명 파일과 자리 표시 파일은 있으나, 이번 확인에서는 실제 원자료가 보이지 않았습니다. 전체 재현에는 별도 원자료 확보가 필요할 수 있습니다.
- `../analysis/`, `../preprocess/`, `../api/`: 분석·전처리·수집 코드. 실행 방법은 [프로젝트 README](../README.md)를 참고하세요.
- `../research_web/`: 연구 결과 웹 페이지. `../scratch/`: 학회 양식 등 작업 참고자료.

## 보존 및 정리 판단

검증 보고서는 `docs/verification/`에 모았으며, 감사 스크립트가 해당 위치와 `data/processed/reactions/`에 산출물을 생성합니다. 연구 요약 표와 차트는 생성 스크립트의 기존 위치를 유지합니다. 과거 감사 기록에 적힌 당시 경로는 이력으로 보존했습니다.
