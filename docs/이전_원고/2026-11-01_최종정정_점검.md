## 3. 2단계: 항목별 논문 수정 전·후 비교 (`docs/이전_원고/기준_원고.md`)

### 3.1 연구 B (뉴스-검색 교차 검증, 4.4절 및 표 4)
- **개정 전 (`docs/이전_원고/2026-11-01_최종정정_이전_원고.md`)**:
  - 표 4에 8개 매칭 쌍 중 5개 쌍의 $h=0$ 행만 발췌하여 제시하고, $h=-1, +1$ 시차 행을 표에서 생략함.
  - 테스트 구간(`2025~2026`, $N=82$)에서 '금리·물가 뉴스 ↔ 금리 검색'($r=+0.3397$, HAC 원시 $p=0.0170$, HAC Holm $p_{\text{holm}}=0.3575$)을 표본 외에서도 유의한 3대 동조 국면 중 하나로 서술함.
  - 공통 앵커(`'은행'`) 분모 제거 민감도 분석을 통해 "공통 분모 아티팩트 가능성을 완전히 기각하였다"고 과장 표현함.
- **개정 후 (`docs/이전_원고/기준_원고.md` 요약 12행, 영문초록 21행, 4.4절 220~254행, 표 4, 결론 276행)**:
  - `data/processed/supplemental_validation/news_search_hac_results.csv`의 **8개 매칭 쌍 전체와 주요 시차($h=0, -1, +1$) 및 구간별(`Train`, `Eval OOS`, `Full`) 유효 표본 수($N=208/207, 82/81, 291/290$), Pearson $r$, 24개 검정 패밀리 기준 Newey-West HAC(`maxlags=4`) Holm 보정 $p$-값(`hac_p_holm`)**을 표 4에 완결성 있게 제시함.
  - **테스트 구간($N=82$)에서 24개 검정 HAC Holm 보정 후 유의한 동시점($h=0$) 양(+)의 관계는 '시황 뉴스 ↔ 국내증시 검색'($r=+0.4984, \text{HAC } p_{\text{holm}}=0.0432$)과 '기업실적 뉴스 ↔ 기업실적 검색'($r=+0.4718, \text{HAC } p_{\text{holm}}=0.0011$) 두 쌍뿐**임을 요약, 초록, 본문, 결론 모두에서 일관되게 명시함.
  - '금리·물가 뉴스 ↔ 금리 검색'($h=0$)은 학습($r=+0.5511, \text{HAC } p_{\text{holm}}=2.57\times 10^{-13}$)과 전체 기간($r=+0.5026, \text{HAC } p_{\text{holm}}=1.29\times 10^{-13}$)에서 유의하나, **테스트 구간에서는 $r=+0.3397$, HAC 원시 $p=0.0170$, HAC Holm $p_{\text{holm}}=0.3575$로 다중검정 보정 후 유의수준을 충족하지 못함**을 정확히 구분함.
  - 앵커 민감도 분석(`news_search_anchor_sensitivity.csv`)에 사용되는 `score`가 절대 검색량이 아니라 **네이버 데이터랩의 원래 상대 검색 지표(조회 구간 내 최댓값=100)**임을 명시하고, 원래 상대 검색 지표의 차분($\Delta\text{score}$)에서도 유사한 동행 관계가 확인되지만 공통 분모나 스케일링 영향이 완전히 제거되었다고 단정하지 않도록 절제하여 기술함(253행).

### 3.2 연구 A (다중 국면 활성화, 4.2절 및 표 2)
- **개정 전**:
  - "단일 국면 강제 할당 시 43.75%의 유효 국면 신호가 손실(누락)된다"고 서술함.
  - 2022~2023년 금리 인상기 대표 복합 조합으로 `macro;realestate`(5회), `macro;market`(5회), `macro;capital`(4회)이 빈번했다고 서술함(실제 2022~2023년 `macro`와 `capital` 동시 활성화는 0개월).
- **개정 후 (`docs/이전_원고/기준_원고.md` 요약 12행, 영문초록 21행, 4.2절 154~176행, 결론 274행)**:
  - `43.75%`(`49/112`: 학습 `42/89 = 47.19%`, 테스트 `7/23 = 30.43%`)의 의미를 **"단일 대표 국면 방식으로 표현을 제한할 경우, 다중 국면 방식에서 관측된 활성 국면 신호 중 43.75%(112건 중 49건)가 별도 국면으로 표현되지 않는다. 이는 표현상 정보 보존성에 관한 결과이며 예측 정확도의 개선을 의미하지는 않는다"**로 정확히 수정함.
  - `single_vs_multi_regime_combinations.csv` 및 `single_vs_multi_monthly.csv`의 실제 집계에 맞춰 전체 기간 상위 2국면 단독 조합(`market;earnings` 5개월, `aichip;capital` 4개월, `macro;realestate` 3개월, `realestate;capital` 3개월, `earnings;capital` 3개월)과 3국면 포함 쌍별 동시 활성화 빈도(2022년 `macro`+`realestate` 5개월[2국면 단독 3 + 3국면 2], 2022~2023년 `macro`+`market` 5개월[2국면 단독 2 + 3국면 3], 2022~2023년 `macro`+`capital` 0개월[전 기간 2024-12의 3국면 조합 1개월만 존재])를 정확히 기재함(175행).
