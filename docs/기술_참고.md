## 1. 파이프라인 (캐시 이후)

본분석은 NMF. 수집·전처리·NMF 국면은 `processed`에 있으면 raw를 다시 받지 않는다.

BERTopic은 `run_pipeline`에 없다 → `python -m analysis.fallback_bertopic`  
PDF는 `python -m analysis.build_results_report` (CSV·QC 묶기, 새 분석 아님)

```text
[캐시] monthly_panel.csv · regime_monthly.csv · changepoints.csv · doc_term.npz
        ↓
[1] 반응      analysis.measure_reactions
        ↓
[2] 강건성    analysis.robustness (2026 제외)
        ↓
[3] RQ4       analysis.rq4_search
        ↓
[4] 폴백      decide_fallback → (조건부) LDA → reactions_lda/
```

```powershell
python -m analysis.run_pipeline
```

| 단계 | 알고리즘 | 비고 |
|------|----------|------|
| 토픽 | NMF(14), seed 42 | 본분석 고정 |
| 국면 | 8대 국면 다중 활성화 (`z >= 0.5`) | 단일 라벨 편향 극복, 월평균 2.24개 |
| 전환 | PELT L2, BIC | 2026-03·07 미포착 |
| 반응·회귀 | 8대 국면 비중 벡터 회귀 (HAC maxlags=3) | R²=22.8%, F=4.75, p=0.00016 |
| 선행성 | 교차상관 (Lead-Lag, h=-2~+2) | 심리 1달, 금리 2달, 코스피 2달 선행 |
| 강건성 | z 임계값 민감도(0.3~0.7) + 2026 제외(60개월) | 유의성 안정 불변 확인 |
| RQ4 | 뉴스↔검색 정합성 | 데이터랩 보조 확인 |
| 폴백 | LDA 조건부, BERTopic 별도 | 본국면 NMF 유지 |

## 2. 모듈·명령

`processed` 캐시 필요. raw 재수집 없음.

| 모듈 | 명령 |
|------|------|
| 통합 | `python -m analysis.run_pipeline` |
| RQ3만 | `python -m analysis.measure_reactions` |
| 강건성 | `python -m analysis.robustness` |
| RQ4 | `python -m analysis.rq4_search` |
| LDA 폴백 | `python -m analysis.fallback_topics` |
| BERTopic | `python -m analysis.fallback_bertopic` |
| NMF 국면 | `python -m analysis.detect_regimes` |
| PDF | `python -m analysis.build_results_report` |

### 전처리 (입력이 바뀔 때만)

| 명령 | 산출 |
|------|------|
| `python -m preprocess.build_corpus` | `news_corpus.parquet` |
| `python -m preprocess.build_doc_matrix` | `doc_term.npz` |
| `python -m preprocess.build_panel` | `monthly_panel.csv` |
| `python -m preprocess.mine_keywords --stage …` | 탐색용 (본국면 아님) |
| `python -m api.collect_ecos` | ECOS |
| `python -m api.collect_datalab` | 데이터랩 |

### 형식 변환 (분석 입력 아님)

`preprocess.csv_to_json`, `preprocess.bigkinds_to_json`

## 3. 주요 함수

| 함수 | 파일 | 역할 |
|------|------|------|
| `fit_nmf` | `detect_regimes.py` | TF-IDF + NMF |
| `map_topics` | 같음 | 토픽→국면 (키워드 질량) |
| `fold_regimes` | 같음 | 8국면 비중 집계 및 다중 활성화 (`z >= 0.5`) |
| `detect_changepoints` | 같음 | PELT |
| `analyze` | `measure_reactions.py` | 반응 산출 묶음 |
| `group_tests` | 같음 | KW / ANOVA / Levene |
| `decide_fallback` | `run_pipeline.py` | LDA 트리거 |
| `fit_lda` | `fallback_topics.py` | LDA 폴백 |
| `run_bertopic` | `fallback_bertopic.py` | 표본 BERTopic |

## 4. 용어집

코드·QC와 같은 뜻으로만 쓴다.

| 용어 | 뜻 |
|------|-----|
| 분석 창 | 2021-01 ~ 2026-07 (67개월) |
| lead-in | 2016-01~ 적재, 차분·시차용 |
| 국면 | 뉴스 8축: 금리·물가·부동산·가계대출·대외통상·AI반도체·시황·기업실적·자본거래. 검색 키워드 묶음은 예전 7개 |
| z-우세 | 국면 비중 z점수 최대 → `dominant_regime` |
| 전량 변환 NMF | IDF 전량, 적합 월 3,000건 층화, W 전량 |
| PELT | 열별 z, 최소 구간 3개월 |
| `kospi_ret_std` | 변동성 표준화 수익률 (2026 강건성) |
| 폴백 LDA/BERTopic | NMF 대체 아님 |
