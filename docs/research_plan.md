# 연구 계획서: 뉴스·검색 데이터 기반 한국형 경제 이슈 국면 탐지

## 1. 연구 주제

**정식 주제**  
뉴스·검색 데이터 기반 한국형 경제 이슈 국면 탐지 및 국면별 시장·심리 지표 반응 분석

**한 줄 정의**  
경제 뉴스와 검색 트렌드를 데이터마이닝하여 시기별 주요 경제 이슈 국면(물가·금리·부동산·대외 등)을 식별하고, 국면별로 코스피·환율·CCSI 등 지표 반응 패턴이 다른지 검증한다.

**기존 연구와의 차별점**

| 구분 | 기존 NSI/감성지수 | 본 연구 |
|------|-------------------|--------|
| 핵심 질문 | 분위기가 긍정/부정인가? | 지금 어떤 이슈가 중심인가? |
| 산출물 | 감성 점수 | 국면 라벨 + 토픽 비중 시계열 |
| 해석 | 심리 온도 | 이슈 유형별 국면 식별 |
| 목표 | 심리 요약 | 국면 탐지 + 국면별 반응 차이 분석 |

> 본 연구는 주가·집값 변동의 “단일 원인 설명 지표”를 만드는 연구가 아니다.

---

## 2. 연구 목적 및 방향성

### 2.1 목적

1. 한국 경제 뉴스·검색 데이터에서 **월(또는 주) 단위 경제 이슈 국면**을 자동 탐지한다.
2. 국면 전환 시점을 식별하고, 국면별로 시장·심리 지표 반응 차이를 측정한다.
3. 감성지수와 구분되는 **이슈 국면 중심의 분석 체계**를 제시한다.

### 2.2 방향성 (할 것 / 하지 않을 것)

**할 것**

- 국면 식별(지금 무슨 이슈인가)
- 국면별 지표 반응의 **연관·패턴 차이** 검증
- 재현 가능한 데이터마이닝 파이프라인 구축

**하지 않을 것**

- “국면이 지수를 움직였다”는 강한 인과 단정
- NSI를 대체하는 만능 단일 설명 지표 개발
- 모든 자산가격 변동의 완전 설명

### 2.3 연구 질문(RQ)

- **RQ1**: 뉴스 토픽 비중으로 한국 경제 이슈 국면을 안정적으로 분류할 수 있는가?
- **RQ2**: 국면 전환 시점을 데이터 기반으로 탐지할 수 있는가?
- **RQ3**: 국면별로 코스피·환율·CCSI 등의 반응 패턴이 다른가?
- **RQ4**(선택): 검색 트렌드는 뉴스 기반 국면을 보조·검증하는가?

## 3. 해야 할 일 (Work Breakdown)

### 3.1 데이터

| 데이터 | 소스 | 역할 | 비고 |
|--------|------|------|------|
| 경제 뉴스 | **빅카인즈** | 본연구 뉴스 코퍼스 | 과거 확보용 본체 |
| 뉴스(파일럿) | 네이버 검색 API | 파이프라인 검증 | 최근 데이터 한계 |
| 검색 트렌드 | **네이버 데이터랩** | 관심도 보조 신호 | 2016-01-01~ |
| 경제지표 | 한국은행 ECOS | 반응 분석 대상 | CCSI, 금리, 환율, 코스피 |

### 3.2 분석 과제

1. 뉴스 전처리(정제, 기간 정렬, 중복 제거)
2. 토픽모델링으로 이슈 분류
3. 월/주 단위 토픽 비중 → 국면 라벨 부여
4. 변화점 탐지로 국면 전환 탐지
5. 검색 트렌드와 국면 정합성 확인
6. 국면별·전환 전후 지표 반응 분석
7. 통제 변수·강건성 검증
8. 논문용 표·그림·해석 정리

### 3.3 국면 라벨(초안)

| 국면 | 예상 키워드/토픽 |
|------|------------------|
| 물가 | 물가, 인플레이션, 원자재, 공공요금 |
| 금리 | 기준금리, 대출, 이자, 긴축 |
| 부동산 | 집값, 전세, 청약, 대출규제 |
| 대외 | 환율, 연준, 수출, 지정학 |
| 성장/실적(선택) | 성장률, 실적, 고용, 경기 |

최종 국면 수는 토픽 결과와 해석 가능성에 따라 4~6개로 조정한다.

## 4. 연구 진행 플로우

```text
[1] 설계
 주제·RQ·기간·국면 정의 확정
        ↓
[2] 데이터 수집
 빅카인즈 뉴스 + 네이버 데이터랩 + ECOS
        ↓
[3] 전처리
 날짜 정규화, 텍스트 정제, 월별 정렬
        ↓
[4] 국면 탐지
 토픽모델링 → 토픽 비중 → 국면 라벨
 변화점 탐지 → 전환 시점
        ↓
[5] 보조 검증
 검색 트렌드와 국면 일치 여부 확인
        ↓
[6] 반응 분석
 국면별 평균 비교
 전환 전후 이벤트 스터디
 통제 회귀(금리·환율 등)
        ↓
[7] 강건성 검증
 기간 분할, 국면 수 변경, 플라시보 전환
        ↓
[8] 논문 작성
 결과표·그림·한계·시사점 정리
```

### 단계별 진행 방식

#### Step 1. 파일럿 (2~3주)

- 현재 네이버 뉴스 + ECOS로 토픽/국면 코드 검증
- 소규모로 “국면 라벨이 해석 가능한지” 확인
- 목적: 방법론 작동 여부 확인 (최종 결과 아님)

#### Step 2. 본데이터 구축 (2~4주)

- 빅카인즈에서 연구 기간 뉴스 수집
- 네이버 데이터랩 이슈별 키워드 그룹 CSV/API 수집
- ECOS 지표 월별 정리
- **공통 기간으로 정렬** (예: 2016년 이후, 뉴스 가용 기간에 맞춤)

#### Step 3. 국면 탐지 모델 (3~4주)

- LDA 또는 BERTopic으로 토픽 추출
- 토픽을 국면 카테고리로 매핑(수동 해석 + 규칙)
- 월별 dominant topic / 토픽 비중 벡터 생성
- 변화점 탐지(예: PELT, Bai-Perron, 간단한 비중 급변 규칙)

#### Step 4. 반응 분석 (2~3주)

- 국면 구간별 코스피 수익률, 환율 변화, CCSI 변화 평균·분산
- 국면 전환 전후 ±1~3개월 경로 비교
- 회귀: 지표변화 ~ 국면더미 + 통제변수

#### Step 5. 강건성·논문화 (2~3주)

- 국면 수·키워드·기간을 바꿔 재추정
- 감성지수(ENSI/NSI식)와 비교해 추가 정보 여부 확인
- 표/그림 확정 후 논문 초고 작성

## 5. 방법론 상세

### 5.1 국면 탐지

1. 문서(뉴스) → 토픽 분포 추정
2. 시점 t의 토픽 비중 \( \theta_t = (\theta_{t1}, ..., \theta_{tK}) \)
3. 국면 라벨:
   - 기본: 최대 비중 토픽을 해당 월 국면으로 사용
   - 개선: 상위 토픽 비중 임계값, 또는 클러스터링으로 국면 정의
4. 전환: \( \theta_t \)의 구조 변화 시점을 전환점으로 탐지

### 5.2 반응 차이 측정

1. **구간 평균 비교**: 국면별 지표 변화량의 평균/표준편차
2. **이벤트 스터디**: 전환 시점 기준 전후 누적 변화
3. **통제 회귀**: 금리·환율·글로벌 요인 통제 후 국면 계수 유의성 확인

### 5.3 해석 원칙

- 가능: “국면별로 반응 패턴이 유의하게 다르다”
- 가능: “국면 정보가 감성 점수만 볼 때보다 해석에 도움이 된다”
- 조심: “국면이 지표 변화를 유발했다” (인과 단정 금지)

## 6. 한계점과 해결 방안

| 한계 | 설명 | 해결 |
|------|------|------|
| 네이버 뉴스 기간 부족 | 최근 기사 위주 | 본데이터는 **빅카인즈** 사용. 네이버는 파일럿만 |
| 검색 데이터 기간 | 데이터랩은 2016-01-01~ | 연구 기간을 2016년 이후로 한정 |
| 검색값 상대성 | 구간 내 상대지수(0~100) | 조회 기간을 config로 고정, 앵커 그룹으로 요청 간 정규화 |
| 검색값 해상도 | 한 요청에 큰·작은 그룹을 섞으면 작은 쪽이 소수점 아래로 눌림 | 요청당 대상 그룹 1개 + 앵커 1개 |
| 토픽 해석 주관성 | 토픽→국면 매핑에 연구자 판단 개입 | 키워드 사전 공개, 복수 매핑·민감도 분석 |
| 인과 식별 어려움 | 뉴스·검색이 사후 반영일 수 있음 | 인과 주장 최소화, 시차·통제·플라시보로 강건성 확보 |
| 동시 이슈 혼재 | 한 달에 여러 이슈 공존 | 단일 라벨 + 토픽 비중 벡터 동시 제시 |
| **본문 절삭** | 빅카인즈 내보내기가 본문을 200자로 자름 (기사 95%) | 원문 전체를 형태소 분석한 `키워드` 컬럼을 토픽 입력으로 사용 |
| **언론 편향** | 코퍼스가 매일경제·서울경제·한국경제 3개 경제지뿐 | **미해결.** 매체 비중 점검이 불가능하다. 종합지를 추가 투입하거나 "경제지 기준 이슈 국면"으로 범위를 좁혀 서술해야 한다 |
| 감성과 이슈 혼동 | 부정 뉴스 ≠ 특정 국면 | 감성 점수는 보조 변수로만 사용 |

## 7. 최종 산출물 (논문에서 내야 할 결과)

### 7.1 필수 산출물

1. **월별 국면 시계열**
   - 예: `YYYY-MM`, `regime_label`, 주요 토픽 비중
2. **국면 전환 목록**
   - 전환 일자(월), 이전 국면 → 이후 국면
3. **국면별 반응표**
   - 국면별 코스피·환율·CCSI 평균 변화 및 변동성
4. **전환 전후 반응 그림**
   - 이벤트 스터디 경로 그래프
5. **검증 결과**
   - 통제 회귀 요약, 강건성 결과
6. **해석 요약**
   - 현재(또는 최근) 주요 국면과 특징

### 7.2 논문 구성(초안)

1. 서론 (배경, 문제, 목적)
2. 관련 연구 (NSI, narrative economics, news topic–macro)
3. 데이터
4. 방법론 (토픽·국면·반응 분석)
5. 결과
6. 논의 및 한계
7. 결론

### 7.3 성공 기준

- 국면 라벨이 실제 경제 이슈 흐름과 대체로 부합
- 국면별 지표 반응에 관측 가능한 차이 존재
- 단순 감성 점수 대비 추가 해석 정보 제공
- 데이터·코드 기준으로 결과 재현 가능

### 7.4 실패로 볼 수 있는 경우

- 토픽이 해석 불가능하게 섞임
- 국면 라벨이 과도하게 불안정
- 국면별 반응 차이가 일관되게 없음  
  → 이 경우에도 “한국 데이터에서 이슈 국면–반응 연결이 약하다”는 결과로 정리 가능

## 8. 데이터·기간 전략 (확정안)

**분석 기간: 2021년 1월 ~ 2026년 7월 (67개월)** — 2026-08-31 확정

당초 2016년 1월부터를 권장했으나, 확보한 빅카인즈 코퍼스가 2021-01부터라
뉴스 가용 기간에 맞춰 분석 창을 조정했다. 월 단위 국면 시계열 67개 시점은
토픽 비중 추정과 변화점 탐지에 충분하다.

ECOS·데이터랩은 **2016-01부터** 받아 둔다. 분석 창 시작 시점(2021-01)의
전월 대비 차분·시차 변수·강건성 검증(기간 분할)에 lead-in이 필요하기 때문이다.
`config/config.yaml`의 `study_period_start`(분석 창)와 `data_buffer_start`(적재 범위)가 이를 구분한다.

| 항목 | 전략 |
|------|------|
| 뉴스 | 빅카인즈 (본체) |
| 검색 | 네이버 데이터랩 |
| 지표 | ECOS |
| 네이버 뉴스 API | 파일럿/프로토타입 전용 |

검색이 일시적으로 없어도 뉴스+ECOS만으로 1차 분석은 가능하나,  
신청서·논문 완성도를 위해 검색은 **보조 검증 데이터로 포함**하는 것을 권장한다.

## 10. 프로젝트와의 연결 (현재 코드베이스)

**현황 (2026-09-03 기준) — Step 2 완료**

Step 1 파일럿·실현가능성 검증은 완료했고, 합성·RSS·네이버 파일럿 산출물과
재실행 스크립트는 본데이터 전환에 맞춰 **삭제**했다. 판정 기록만
`docs/feasibility_report.md`에 남아 있다.

| 소스 | 적재 상태 | 기간 |
|------|-----------|------|
| 빅카인즈 | 61개 엑셀 998,020건 → 코퍼스 **931,709건** | 2021-01 ~ 2026-07 (67개월, 결손 없음) |
| ECOS | CCSI·KOSPI·USD_KRW·BASE_RATE·CPI, 127개월 결측 없음 | 2016-01 ~ 2026-07 |
| 데이터랩 | 대분류 7 + 세부 28그룹, 월·일 | 2016-01 ~ 2026-07 |

내보내기 상한(20,000건) 문제는 해소됐다. 61개 파일 어느 것도 상한에 닿지 않는다.
코퍼스 투입 과정에서 998,020건 중 빅카인즈 자체 제외 플래그 53,194건,
파일 구간 중복 12,976건, 키워드 없는 141건을 걸러 931,709건을 남겼다.
중복 판정은 URL을 1순위로 쓴다. `뉴스 식별자`는 엑셀에서 float으로 읽히면
정밀도가 날아가 같은 기사가 서로 다른 값이 되므로 쓰지 않는다.

**국면 대분류 재설정.** 3.3절의 초안(물가·금리·부동산·대외·성장)을 코퍼스 근거로 바꿨다.
문서 표본 201,000건 NMF 14토픽과 어휘별 월간 빈도 시계열 상관 군집이 공통으로 지목한
축을 채택했다.

| 대분류 | 근거 토픽 (평균 비중) | 비고 |
|--------|----------------------|------|
| 물가 | T1 거시·물가·금리 (8.4%) | |
| 금리 | T1 | |
| 부동산 | T2 아파트·분양 (6.9%) | |
| 가계대출 | T13 대출·은행·가계 (6.0%) | 금리와 피크 시점이 다름 (2023-12 vs 2022-07) |
| 대외통상 | T7 수출·제조 (9.9%) + T12 해외증시 (4.5%) | |
| AI반도체 | T10 AI·반도체 (7.9%) | **신설.** 2022-09 저점 → 2026-06 16.2%, 기간 내 변동 최대 |
| 증시실적 | T4 실적 (6.6%) + T5·T8 증시 (9.6%) + T11 자본거래 (7.8%) | 초안의 `성장`을 대체 |

`성장`은 대응 토픽이 잡히지 않아 뺐다. 관련 어휘가 기업실적과 증시로 갈라져 있었다.

다음 실행 순서:

1. 토픽모델링 → 월별 토픽 비중 → 국면 라벨 (`data/processed/regimes`)
2. 변화점 탐지 → 국면 전환 시점
3. 국면별 지표 반응표 (`data/processed/reactions`)
4. ENSI/감성 비교는 보조로만 필요 시 추가

## 11. 핵심 요약 (제출·발표용)

- **주제**: 한국형 경제 이슈 국면 탐지 및 국면별 지표 반응 분석
- **목적**: 현재 주요 이슈 국면 식별 + 국면별 반응 패턴 제시
- **방법**: 토픽모델링, 변화점 탐지, 이벤트 스터디, 통제 회귀
- **데이터**: 빅카인즈 뉴스 + 네이버 데이터랩 + ECOS
- **결과물**: 국면 시계열, 전환 시점, 국면별 반응표, 논문
- **한계 대응**: 네이버 뉴스 한계 → 빅카인즈, 인과 과해석 금지, 강건성 검증 강화
