# S5. 토픽–국면 매핑 사전

**코드·입력** — `api/datalab_keyword_sets.py::KEYWORD_SETS`와 `analysis/validate_strict_oos_forecast_v4.py`의 `DOMAIN_SPEC`, `build_domain_pairs()`, `claim_terms()`, `map_topics()`를 사용한다. 기준 모델의 순서가 고정된 어휘와 `nmf_H.npy`가 투입된다. 생성 순서대로 사전을 내보낸 전체 목록은 [S5_domain_dictionary.csv](S5_domain_dictionary.csv)에 있다.

긴 사전 키워드부터 어휘를 배정하고, 길이가 같으면 코드의 도메인 순서 및 키워드 순서에 따른다. 먼저 완전 일치를 검사하고, 두 글자 이상인 키워드는 부분 일치도 검사한다. 이미 배정된 어휘는 유지한다. 1위 도메인 질량을 토픽의 전체 어휘 가중치 합으로 나눈 값이 0.01 미만이면 잔차, 2위와 1위 도메인 질량의 비가 0.90 이상이면 경합이다.

**출력·환경** — `data/processed/reactions/phase5_6_topic_regime_mapping.csv`, S5 사전 CSV. Python 3.13.15, NumPy 2.5.1, pandas 3.0.5. 사전 내보내기는 S3의 `verify_panels.py`가 수행한다.

**검산** — 8개 도메인에 139개 도메인·키워드 행. 기준 사전 해시 `B34BC1A6E2AEEC6E97CEF7A5C508CE7BF3118EC958874B11A6AC15E870A27CC4`와 일치했다. 기준 매핑에는 14개 토픽 중 8개 토픽이 6개 국면에 배정되어 있다. 기준 결과에서 가계대출과 대외통상은 독립 국면으로 배정되지 않았다.
