# S4. 학습 표본과 고정 모델

**코드·입력** — `analysis/validate_strict_oos_forecast_v4.py::run_core`, `preprocess/mine_keywords.py::_tokens`. 입력은 `data/processed/corpus/news_corpus.parquet`, 전체 실행에는 `data/processed/panel/monthly_panel.csv`도 필요하다. 학습 2021-01~2024-12 643,095건, 테스트 2025-01~2026-07 288,614건. 학습 문서빈도 200 이상, 학습 문서 대비 0.15 이하, 최대 30,000개에서 22,193개를 확정했다. 문서빈도 내림차순과 어휘 오름차순으로 정렬한다. 학습 월마다 시드 42로 3,000건씩 비복원 추출한다.

**적합·출력** — 144,000건에서 평활 IDF와 L2 정규화 TF-IDF, NMF 14토픽을 적합한다. NMF는 `nndsvd`, 좌표 하강법, Frobenius 손실, 400회, 허용오차 `1e-4`, 시드 42다. 전량 투영에는 모델을 고정한다. 출력은 `data/processed/phase5_6_artifacts/RUN_PHASE5_6_20261027_184959/`의 `fit_sample_ids.csv`, `vocab_idf.csv`, `nmf_H.npy`, `models.joblib`, `monthly_topic_share.csv`, `core_meta.json`이다.

**표 4–5의 품질·안정성** — `analysis/reviewer_readiness/compare_nmf_lda.py`는 같은 학습 표본과 어휘에서 토픽 수 10·12·14·16을 비교한다. 내부 검증 표본은 학습 잔여 문서에서 월 1,000건씩 시드 1042로 추출한다. `analysis/reviewer_readiness/run_topic_stability.py`는 학습 표본의 월별 80% 재표본화 10회(101–110)와 초기화 변경 11회(`nndsvda` 42, `nndsvdar` 201–205, `random` 301–305)를 실행한다. 산출물은 `data/processed/reviewer_readiness/RUN_20261106_161800/`의 `topic_model_comparison_metrics.csv`, `topic_stability_runs.csv`, `topic_stability_summary.csv`, `regime_mapping_stability.csv`다. 기존 기록에서 6개 국면이 21/21회 재현되었다.

**환경·검산** — S3 기준 환경과 시드를 적용한다. 이번 검산에서 기준 코퍼스 SHA-256, 22,193개 어휘, 144,000 표본, `H`의 14×22,193 크기를 확인했다. 품질·안정성의 다회 적합은 기존 검증 기록을 인용했다.
