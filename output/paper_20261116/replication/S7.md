# S7. 주별 뉴스·검색 교차검증

## 월별·주별 입력 행렬

| 단계 | 월별 | 주별 |
|---|---|---|
| 기사 입력 | `run_core()`가 식별자·월·키워드의 결측·공백과 식별자 중복을 검사하고 월·식별자·키워드 순서로 안정 정렬한다. | `run_study_b()`가 같은 코퍼스에서 날짜·월·키워드 등을 읽고 2021-01 이후의 기사에 ISO 연도·주차를 부여한다. |
| 토큰 처리 | `preprocess/mine_keywords.py::_tokens`가 쉼표 분리, 양끝 공백 제거, 짧은 토큰·달력 표현·숫자·상투어 필터 및 기사 내 중복 제거를 수행한다. | 쉼표로 분리한 문자열이 고정 어휘에 정확히 일치할 때 목록에 보관한다. 개별 토큰 공백 제거와 기사 내 중복 제거 단계가 없다. |
| CSR | 어휘 열당 0 또는 1이다. | 목록 위치마다 값 1을 추가한다. 반복 토큰은 같은 CSR 열의 반복 엔트리가 된다. |
| 투영·집계 | 고정 TF-IDF·NMF로 투영하고 기사별 W를 행 합으로 나눈 뒤 월별 집계한다. | 같은 고정 어휘·IDF·NMF 기저를 불러와 `tfidf.transform()`, `nmf.transform()`만 호출한다. W의 행 합이 양수인 기사를 정규화한 뒤 주별로 평균하고 동일 토픽–국면 매핑을 합산한다. |

이 코퍼스에서 고유 어휘에 일치하는 토큰의 집합은 두 경로가 같았고, 주별 입력에서 고정 어휘의 반복이 있는 기사는 929,521건이었다. 양쪽에서 고정 어휘에 걸리지 않은 기사는 11건이었다. 이 값은 앞선 전수 대조 결과다. 산출된 표 13을 재현할 때 주별 CSR 경로를 그대로 사용한다.

## 검색 요청과 주별 분석

[S7_search_groups.json](S7_search_groups.json)에 수집에 사용한 대분류 7개·세부 그룹 28개·은행 앵커의 전체 검색어를 보관했다. `api/datalab_keyword_sets.py`가 그룹을 정의하고 `api/collect_datalab.py::collect_level`이 2016-01-01~2026-07-31을 일 단위로 조회한다. 요청마다 대상 그룹 1개와 은행 앵커를 묶는다. 기기·성별·연령은 지정하지 않는다. 대상 지수 결측은 0으로 채우고, 앵커가 양수인 날에 대상 지수를 앵커로 나눈다.

**주별 생성 코드와 입력** — `analysis/supplemental_validation/run_study_b.py`의 `run_study_b()`. 입력 파일은 아래 다섯 개다.

- `data/processed/corpus/news_corpus.parquet`
- `data/processed/phase5_6_artifacts/RUN_PHASE5_6_20261027_184959/models.joblib`
- `data/processed/reactions/phase5_6_topic_regime_mapping.csv`
- `data/raw/datalab/datalab_regime_daily.csv`
- `data/raw/datalab/datalab_sub_daily.csv`

**출력·검정** — 각 대상의 일별 비율을 ISO 주별로 평균하고, 금리+물가는 두 그룹의 주별 평균을 다시 평균한다. 뉴스와 검색 열을 ISO 주차에서 결합하여 `data/processed/supplemental_validation/news_search_weekly_panel.csv`를 생성한다. 2025-W01은 테스트의 첫 원시 주다. 전체 292주, 학습 209주, 테스트 83주를 각자 차분해서 동시점 유효 표본 291·208·82주를 얻는다. `verify_hac_news_search.py`가 8쌍×3시차마다 표준화한 차분에 HAC 시차 4를 적용하고, 구간별 Holm 보정 후 `news_search_hac_results.csv`를 출력한다. 8쌍은 금리·물가–금리, 물가, 금리+물가의 3쌍과 부동산–부동산, 첨단산업–AI반도체, 시황–국내증시, 기업실적–기업실적, 자본거래–공모주다.

표 14의 앵커 민감도는 `analysis/supplemental_validation/verify_anchor_sensitivity.py`가 결합 패널과 일별 파일을 읽어 `news_search_anchor_sensitivity.csv`로 산출한다. `analysis/reviewer_readiness/verify_search_robustness.py`는 이 파일과 패널 및 기준 HAC 결과를 읽는다. HAC 시차 2·4·8, 부트스트랩 블록 2·4·8주, 2,000회, 시드 42를 적용하고 `data/processed/reviewer_readiness/RUN_20261106_161800/`에 `news_search_hac_lag_sensitivity.csv`와 `news_search_block_bootstrap_ci.csv`를 쓴다.

**환경·검산** — S3 기준 버전과 동일하다. 수집본의 35개 검색어 그룹과 코드가 일치했고, 저장 주별 패널에서 72개 HAC 검정을 재계산했다. 상관계수는 기준 결과의 소수 넷째 자리까지 모두 일치했다. Holm 보정 p값 최대 차이는 8.4e-17 미만이다. 테스트 동시점 시황은 r=0.4984, p=0.0432, 기업실적은 r=0.4718, p=0.0011이다. 주별 원자료 전량 재투영은 이번 검산에 포함하지 않았다.

## 표 14의 두 불확실성 지표

HAC 표준오차는 표준화한 주별 차분 회귀에서 시차 2·4·8주까지의 이분산성과 자기상관을 반영한다. 각 시차 설정과 분석 구간에서 8쌍×3개 뉴스–검색 시차, 총 24개 p값을 한 묶음으로 Holm 보정한다.

이동 블록 부트스트랩은 동시점의 뉴스·검색 차분을 짝으로 유지하면서 연속 블록을 2,000회 재표집한다. 표 14의 4주 블록 구간은 해당 쌍의 재표집 상관계수 분포에서 2.5·97.5 백분위수를 취한 95% 구간이다. 이 구간에는 다중비교 보정이 적용되지 않는다. 따라서 구간의 0 포함 여부와 24개 검정의 보정 p값은 서로 다른 불확실성 추정과 판정 기준을 반영한다.

금리·물가–금리의 구간은 [0.1315, 0.5054]이지만 HAC 시차 4의 원시 p값 0.0170은 Holm 보정 후 0.3575다. 시황은 시차 8에서 보정 p=0.0616으로 5% 기준을 넘고 4주 블록 구간은 [0.2079, 0.6367]이다. 기업실적은 세 HAC 시차 모두에서 5% 기준을 충족한다. 원고의 다중비교 유의성 판단에는 HAC·Holm 결과를 사용한다. 구현 근거는 `analysis/reviewer_readiness/verify_search_robustness.py`의 `holm_adjust()`, `moving_block_bootstrap_corr()`와 두 출력 CSV에 있다.

최종 제출 점검에서 `verify_panels.py`로 표 14의 Holm p값 9개와 4주 블록 신뢰구간 경계값 6개를 다시 계산하였고, 원고의 표시 정밀도에서 모두 일치했다.
