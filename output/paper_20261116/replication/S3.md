## 원자료에서 분석을 구성하는 순서

기존 분석 모듈은 로컬 산출물 경로에 파일을 쓰므로 별도 실행용 저장소 복사본에서 아래 순서를 사용한다.

1. 빅카인즈 엑셀을 S1 경로에 두고 `python -m preprocess.build_corpus`로 코퍼스를 구축한다.
2. 연구에 사용한 ECOS·데이터랩 입력을 배치한다. 외부 서비스 재조회가 필요한 경우 `python -m api.collect_ecos`, `python -m api.collect_datalab`가 수집기다. 배치한 스냅샷을 `python -m preprocess.build_panel`로 월별 패널에 결합한다.
3. `python -m analysis.validate_strict_oos_forecast_v4`로 학습, 매핑, 월별 국면, 예측 결과를 생성한다. 새 실행은 별도의 타임스탬프 폴더를 만든다. 기존 기준 결과와 비교할 때에는 동일 실행에서 나온 모델과 매핑을 함께 사용한다.
4. 표 4–7, 8–12 검증의 세부 경로는 S4–S6에 있다. 검색 패널은 `python -m analysis.supplemental_validation.run_study_b`, 표 13은 `python -m analysis.supplemental_validation.verify_hac_news_search`로 계산한다. 주별 스크립트는 기존 기준 실행 경로를 상수로 사용한다. 새 모델 재적합을 검증할 때는 복사본에서 명시적으로 그 경로와 짝이 맞는 매핑 경로를 지정해야 한다.
5. 표 14와 수렴 민감도는 S7–S8의 모듈과 참조 결과를 이용한다.

**입출력·검산** — 각 단계가 사용하는 입력과 파일 출력은 S1–S2 및 S4–S8에 명시했다. 이번에는 동일 환경에서 기준 패널 검산과 원본 분류 검증을 수행했다. 새 환경에서 원자료부터 모든 명령을 연속 실행한 결과는 확인 범위에 포함되지 않는다.
