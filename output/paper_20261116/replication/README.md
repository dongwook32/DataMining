# 6국면 Strict OOS 재현 안내

대상 원고는 `경제이슈국면탐지_v4_제출검토본.pdf`이다. PDF의 첨부 파일 패널에서 `replication.zip`을 저장하고 압축을 풀어 이 파일을 연다. 별도로 제공되는 `DataMining_v4_submission.zip`에도 PDF와 동일한 `replication/` 폴더가 있다.

명령은 연구 저장소와 S8의 입력을 확보한 환경에서 실행한다. 제출 ZIP의 `replication/`을 저장소의 `output/paper_20261116/` 아래에 두면 문서에 기록된 상대 경로를 사용할 수 있다. 환경과 검산 명령은 S3, 자료 제공 범위는 S8에 있다.
