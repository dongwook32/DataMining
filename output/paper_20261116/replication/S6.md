# S6. 월별 패널과 시장 검증

**입력·코드** — `api/collect_ecos.py`, `api/ecos_indicators.py`, `preprocess/build_panel.py`를 사용한다. 월별 패널 입력은 `data/raw/ecos/ecos_monthly.csv`, `data/raw/datalab/datalab_{regime,sub}_monthly.csv`, 데이터랩 일별 자료 및 `data/processed/corpus/corpus_monthly_counts.csv`다. 2016-01~2026-07을 보관하여 차분과 변동성 추정에 필요한 이전 관측치를 확보한다.

| ECOS 월별 지표 | 통계표 / 항목 |
|---|---|
| 코스피 월말 종가 | `901Y014 / 1070000` |
| 원/달러 월말 | `731Y004 / 0000001 + 0000200` |
| 기준금리 | `722Y001 / 0101000` |
| 소비자심리지수 | `511Y002 / FME + 99988` |
| CPI | `901Y009 / 0` |

`build_panel.py::add_indicator_derivatives`가 코스피·환율에 100을 곱한 로그차분, 기준금리·소비자심리에 단순 차분을 계산한다. 코스피 당월 로그수익률을 직전 12개월 수익률의 표본 표준편차로 나눈다. 출력 `data/processed/panel/monthly_panel.csv`와 `data/processed/reactions/phase5_6_train_only_regime_monthly.csv`를 월로 결합한다.

| 논문 결과 | 실행 코드와 산출물 |
|---|---|
| 표 7–8 국면 및 다중 활성 | `analysis/supplemental_validation/run_study_a.py` → `data/processed/supplemental_validation/single_vs_multi_{metrics,monthly}.csv`. 학습 48개월로 표준화한 점수에서 z ≥ 0.5를 사용한다. |
| 표 9 사례 월 | `analysis/reviewer_readiness/analyze_multi_regime_cases.py` → `data/processed/reviewer_readiness/RUN_20261106_161800/multi_regime_case_manifest.csv`와 사례 요약 파일. |
| 표 10 회귀 | `analysis/verify_three_analyses.py::run_ols_verification` → `data/processed/reactions/verification_ols_results.csv`의 Phase 5.6 결과. 절편 포함 OLS, HAC 시차 3, 여섯 국면 계수에 Holm. |
| 표 11–12 시차상관·경보 | 같은 파일의 `run_correlation_lag_verification()`, `run_warning_verification()` → `data/processed/reactions/verification_correlation_lag_results.csv`, `verification_warning_performance_results.csv`. |

**환경·검산** — S3의 Python·pandas·statsmodels 버전. 전체 `verify_three_analyses.py` 실행에는 과거 8국면 `data/processed/regimes/regime_monthly.csv`도 필요하다. [verify_panels.py](verify_panels.py)는 최종 6국면 입력만 읽어 표 8과 표 10을 재계산한다. 이번 결과는 39/67개월, 49/112건, 회귀 R² 0.1618787071로 일치했으며 6개 계수와 Holm p값도 논문 표의 반올림 자리에서 일치했다. 표 11·12의 이번 자료 구성에서는 기존 결과와 검증 기록을 참조했다.
