# 스크립트 안내

| 폴더 | 역할 |
|---|---|
| `01_collect/` | 수집 스냅샷을 검증할 때 사용하는 데이터랩 검색어 정의 |
| `02_preprocess/` | 빅카인즈 기사 정규화·중복 제거와 월별 패널 구축 |
| `03_embed/` | 학습 어휘, TF-IDF 변환, 학습 표본과 토픽 가중치의 계산 |
| `04_cluster/` | NMF 학습 진입점, 토픽의 경제 국면 배정, 다중 국면 분석 |
| `05_validate/` | 토픽 품질·안정성, 모델 수렴·강건성, 논문 주요 수치 검산 |
| `06_analyze/` | 시장·예측·검색 분석과 결과 파일 출력 |
| `_shared/` | 연구 설정과 공통 함수, 이전 분석 진입점 보관 |
| `run_all.py` | 원자료부터 새 실행 폴더에 결과를 저장하는 전체 실행 |

`python script/run_all.py --dry-run`으로 실제 계산 순서를 확인할 수 있습니다. 일부 후속 검증은 시장·검색 분석 결과를 입력으로 쓰므로 폴더 번호와 정확히 같은 순서로 진행되지는 않습니다. 연구 모듈은 원래의 import 경로를 유지하도록 실행별 `work/`에 배치됩니다.
