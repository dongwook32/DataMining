### 1.1 검증 목적

## 9. 핵심 판정 질문 7개 (Q1 ~ Q7)에 대한 직접 답변

### Q1. NMF-400과 NMF-800의 월별 국면 시계열은 얼마나 유사한가?
- **답변**: 토픽 매핑이 불변인 5대 국면(`macro`, `aichip`, `market`, `earnings`, `capital`)은 전체 67개월 동안 **`Pearson r = 0.9910 ~ 0.9998`** (`aichip 0.9996`, `market 0.9997`, `earnings 0.9998`, `macro 0.9952`, `capital 0.9910`), **`MAE = 0.0002 ~ 0.0080`**으로 사실상 동일한 시계열이다. 미배정 잔여 비중(`residual_share`) 역시 `r = 0.9962`로 일치한다.

### Q2. `Topic 2`의 `realestate -> hhdebt` 분리가 월별 국면 비중에 어떤 영향을 주는가?
- **답변**: 기존 `NMF-400`에서 2개 토픽(`T2+T3`)이 병합되어 평균 `12.28%`를 차지하던 `realestate` 국면이, `NMF-800`에서는 **순수 부동산(`T3`: 평균 `6.05%`)**과 **가계대출(`T2`: 평균 `5.99%`)**로 절반씩 분리된다. 두 시계열을 합산한 `realestate_legacy`(`T3+T2`, 평균 `12.04%`)는 기존 `NMF-400` `realestate`와 전체 기간 **`r = 0.9648`** (`MAE = 0.0026`), 테스트 19개월 **`r = 0.9693`** (활성 일치율 `100.0%`)로 일치하는 반면, 분리된 `T3`와 `T2` 상호 간 상관은 전체 기간 `r = 0.0467`(`p = 0.7077`), 학습 기간 `r = -0.3038`(`p = 0.0358`)에 불과하여, 기존 `realestate` 시계열 내에 서로 다른 두 경제 동학(실물 주택분양 vs 가계대출·주담대 규제)이 혼재되어 있었음을 보여준다.

### Q3. 다중 국면 활성화가 단일 국면보다 많은 정보를 보존한다는 결론은 유지되는가?
- **답변**: **완벽히 유지되며 오히려 강화된다.** 단일 대표 국면(`argmax`) 방식에서 누락되는 활성 신호 비율은 `NMF-400`(`49/112`건 = **`43.75%`**) 대비 `NMF-800` Legacy-6 합산에서 **`43.24%`**(`48/111`건), `NMF-800` 6국면 부분집합에서 **`43.64%`**(`48/110`건), `NMF-800` 고유 7국면 체제에서 **`50.40%`**(`63/125`건)로 모든 패널 구성에서 `43%~50%`의 활성 신호가 단일 국면 방식에서 손실된다.

### Q4. KOSPI 및 거시지표 HAC 회귀의 핵심 유의성·계수 부호가 유지되는가?
- **답변**: **100% 유지된다.** 주 분석인 `kospi_ret_std`(전체 67개월, HAC `maxlags=3`)에서 `NMF-400`(`R² = 0.1619, HAC F = 4.6833, p = 0.000573`)과 비교할 때, `NMF-800` 7국면(`R² = 0.1698, HAC F = 4.5052, p = 0.000448`) 및 `NMF-800` Legacy-6(`R² = 0.1696, HAC F = 5.0921, p = 0.000278`) 모두에서 모형 설명력이 소폭 상승하고, **기존 6개 국면 변수의 계수 부호(전부 음수)와 Holm 보정 후 유의 변수 2개(`z_macro`: `p_holm = 0.0208 [7국면] / 0.0062 [Legacy-6]`, `z_capital`: `p_holm = 0.0208 [7국면] / 0.0163 [Legacy-6]`)가 100% 동일하게 유지된다.** 또한 보조 거시 회귀(`base_rate_diff`)를 통해 기존 `realestate`의 금리 민감성이 `hhdebt` 성분(`p_raw = 0.0165`)에서 비롯되었음이 명확히 해명된다.

### Q5. Strict OOS 경고 성능 및 금리 인상 포착 결과는 어떻게 변하는가?
- **답변**: **`z_macro >= 0.5` 기준 경고 결과는 단 한 달의 차이도 없이 100% 동일하다.** 전체 65개월(`TP=9, FP=4, FN=36, TN=16`), 학습 48개월(`TP=9, FP=3, FN=27, TN=9`), Strict OOS 17개월(`TP=0, FP=1, FN=9, TN=7`, 경보월 `2026-03` 1건)의 혼동행렬과 한국은행 기준금리 인상 포착률(전체 `7/11 = 63.64%`, 본격 인상기 `7/7 = 100%`, 평균 선행 `1.0개월`)이 두 모델에서 완전히 일치한다. 추가적으로 `NMF-800`에서는 `share_hhdebt` 복원에 따라 Phase 5.6 `H1`(`kospi_ret` 19개월 OOS ARX) 예측이 작동하여 `AR(2)` 기준선 대비 `RMSE`가 `15.2825 -> 13.8687`로 감소하는 보조 결과가 확인되었다.

### Q6. 네이버 검색량 주별 교차검증 결과는 유지되는가?
- **답변**: **완전히 유지된다.** 사전 정의된 24개 검정 패밀리에서 전체 기간(`N=291`주) 및 학습 기간(`N=208`주)의 Holm 보정 유의성 판정(`p_holm < 0.05`)은 **`NMF-400`과 `NMF-800` 간에 24/24건(100.0%) 일치**한다. Strict OOS(`N=82`주) 동시점(`h=0`)에서도 `기업실적`(`r = 0.4718 -> 0.4687`, `p_holm = 0.0011 -> 0.0014`)과 `시황`(`r = 0.4984 -> 0.4920`, `raw p = 0.0020 -> 0.0023`, `lag=2 p_holm = 0.0339 -> 0.0409`, `lag=4 p_holm = 0.0432 -> 0.0508`, MBB 95% CI `[0.2012, 0.6335]`)의 강한 동시적 동조화가 그대로 재현된다.

### Q7. 논문에서 `NMF-400` 기준 결과를 유지하고 `NMF-800`을 강건성 검증으로 제시하는 것이 타당한가, 아니면 본문 기준 자체를 `NMF-800`으로 교체해야 하는가?

## 11. 한계점 및 과장 금지 준수 사항

1. **인과성 및 선행 예측력 과장 금지**:
   - `NMF-400`과 `NMF-800` 모두에서 월별 KOSPI HAC 회귀(`kospi_ret_std`)와 주별 네이버 검색량 교차검증(`h=0`)은 **동시점(Contemporaneous) 공변 및 의제 동조화**를 입증하는 결과이며, 뉴스 국면이 미래 주가나 미래 검색량을 일방적으로 선행 예측(Granger 인과)한다는 증거가 아니다.
2. **Strict OOS 주가 조기경보의 한계 명시**:
   - 학습 구간에서 관찰된 거시 불확실성(`z_macro >= 0.5`) 및 가계대출(`z_hhdebt >= 0.5`)의 주가 하락/급락 동반 현상은 2025-01~2026-05 Strict OOS 구간(17개월)에서 조기경보 적중(`TP=0`)으로 이어지지 않으므로, 단일 임계값 규칙을 실전 투자나 주가 하락 예측 도구로 과장해서는 안 된다.
3. **네이버 데이터랩 상대지수 정규화 한계**:
   - 주별 차분(`diff`)은 학습/평가 구간 내부에서 엄격히 분리 수행되었으나, 데이터랩 원자료 자체가 조회 기간 전체 최댓값(`=100`) 대비 상대지수로 제공되는 API 구조적 특성이 있음을 투명하게 밝혀야 한다.
