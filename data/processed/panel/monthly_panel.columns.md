# monthly_panel.csv — 컬럼 설명

월 × 54열. 127개월(2016-01~2026-07), 분석 창은 `in_study`로 구분.

## 키

| 컬럼 | 설명 |
|------|------|
| month | 연-월 (`2021-01`). 다른 산출물과의 조인 키 |
| date | 그달 1일 (`2021-01-01`) |
| in_study | 분석 창(2021-01~2026-07) 여부. 앞 60개월은 lead-in |

## 지표 원계열 (ECOS)

| 컬럼 | 설명 |
|------|------|
| KOSPI | 코스피 월말 종가 |
| USD_KRW | 원/달러 환율 (월말) |
| CPI | 소비자물가지수 (2020=100) |
| CCSI | 소비자심리지수 |
| BASE_RATE | 한국은행 기준금리 (%) |

## 지표 파생

레벨은 모두 비정상 계열이라 회귀에는 아래를 쓴다.

| 컬럼 | 설명 |
|------|------|
| kospi_ret | 코스피 월 로그수익률 ×100 (%) |
| usdkrw_ret | 환율 월 로그변화율 ×100 (%). 양수 = 원화 약세 |
| cpi_mom | CPI 월 로그변화율 ×100 (%) |
| ccsi_diff | CCSI 전월차 (포인트) |
| base_rate_diff | 기준금리 전월차 (%p) |
| cpi_yoy | CPI 전년동월비 (%). 전월비의 계절성을 피할 때 사용 |
| kospi_vol3 | 직전 3개월 `kospi_ret` 표준편차. 반응 '크기'가 아닌 '불확실성' 비교용 |
| kospi_vol12 | 직전 12개월 `kospi_ret` 표준편차 |
| kospi_ret_std | `kospi_ret / kospi_vol12.shift(1)`. 변동성 표준화 수익률 |

`kospi_ret_std`는 2026년 분산 급증이 국면 계수를 삼키는 것을 막기 위한 강건성 변수다.
분모에 `shift(1)`을 걸어 당월 정보가 스케일에 새지 않게 했다.

## 뉴스 (빅카인즈 코퍼스)

| 컬럼 | 설명 |
|------|------|
| news_n | 그달 코퍼스 기사 수. 2021-01 이전은 결측 |

## 검색 (네이버 데이터랩 대분류 7국면)

`{slug}`은 국면의 ASCII 약칭으로 `config/config.yaml`의 `regimes.slugs`가 정의한다.

| 국면 | slug |
|------|------|
| 물가 | prices |
| 금리 | rates |
| 부동산 | realestate |
| 가계대출 | hhdebt |
| 대외통상 | trade |
| AI반도체 | aichip |
| 증시실적 | equity |

국면마다 다섯 열이 있다.

| 컬럼 | 설명 |
|------|------|
| srch_{slug} | `score_rel` 원값 (= 데이터랩 점수 ÷ 앵커 점수). 요청 간 비교 가능 |
| srch_{slug}_z | 위 값의 전기간(127개월) z-점수 |
| srch_{slug}_share | 7국면 합 대비 점유율. 한 행의 7개 합 = 1 |
| srch_{slug}_dlog | 전월 대비 로그변화율 ×100 (%) |
| srch_{slug}_dstd | 그달 일별 `score_rel`의 표준편차. 이슈의 돌발성 대리변수 |

`_z`는 절대 관심 수준, `_share`는 국면 간 관심 배분을 본다. 둘은 다른 질문에 답하므로
어느 쪽을 쓸지 분석 목적에 맞춰 골라야 한다.
