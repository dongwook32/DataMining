# ECOS 경제지표

한국은행 ECOS Open API로 받은 월별 시계열입니다.

재수집: `python -m api.collect_ecos --start 2016-01 --end 2026-07`

## 수집 기록
| 파일 | 수집 시각 (KST) | 조회 구간 |
|------|-----------------|-----------|
| `ecos_monthly.csv` | 2026-09-03T01:10:05+09:00 | 2016-01 ~ 2026-07 |

`collected_at` 컬럼에도 같은 시각이 들어 있습니다. 재수집하면 수집기가 자동으로 갱신합니다.

컬럼 한 줄 설명: 같은 폴더의 [`ecos_monthly.columns.md`](ecos_monthly.columns.md)

## 파일
| 파일 | 형식 |
|------|------|
| `ecos_monthly.csv` | 월당 1행, 지표를 컬럼으로 (병합·회귀용) |

## 스키마
| 컬럼 | 설명 |
|------|------|
| date | YYYY-MM-01 (월초로 통일) |
| CCSI / KOSPI / USD_KRW / BASE_RATE / CPI | 각 지표 수치 |
| collected_at | API 호출 시각 (ISO 8601, Asia/Seoul) |

## 지표 정의
정의는 `api/ecos_indicators.py`에 있고, 코드는 ECOS 항목 목록으로 실측 확인한 값입니다.

| 지표 | 통계표 | 항목 | 내용 |
|------|--------|------|------|
| CCSI | 511Y002 | FME / 99988 | 소비자심리지수 (전국·전체) |
| KOSPI | 901Y014 | 1070000 | KOSPI 월말 종가 (1980.01.04=100) |
| USD_KRW | 731Y004 | 0000001 / 0000200 | 원/미국달러 매매기준율 **월말** |
| BASE_RATE | 722Y001 | 0101000 | 한국은행 기준금리 (연%) |
| CPI | 901Y009 | 0 | 소비자물가지수 총지수 (2020=100) |

항목코드 확인: `python -m api.collect_ecos --list-items 511Y002`

## 주의
- `USD_KRW`는 **말일자료**(0000200)입니다. KOSPI 월말종가와 시점 축을 맞추기 위한 선택이며,
  월평균이 필요하면 항목을 `0000100`으로 바꾸세요.
- 지표는 뉴스 코퍼스보다 긴 2016-01부터 받습니다. 분석 창(2021-01~) 시작 시점의 차분·시차 계산에 필요합니다.
